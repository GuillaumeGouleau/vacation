Bienvenue !

Cette application permet à toute la famille de noter les dépenses des vacances depuis chaque téléphone, avec un total partagé en temps réel (CAD $ / EUR €) et un suivi de budget.

Vous avez reçu un lien de partage ?

Ouvrez simplement ce lien : tout se configure automatiquement. Rien d'autre à faire.

Première installation (une seule fois, par l'organisateur) :

1. Créez un projet gratuit sur console.firebase.google.com (compte Google).
2. Dans le projet : Créer > Realtime Database > démarrer en mode test.
3. Dans Paramètres du projet ⚙️ > Général > Vos applications, ajoutez une application Web et copiez le bloc firebaseConfig.
